Biblioteca de transformaciones a RDF

Este espacio reúne las transformaciones definidas para convertir distintos conjuntos de datos en RDF utilizando los modelos semánticos de EDINT. Cada mapping se presenta como una unidad reutilizable, con acceso directo a su documentación y a los ficheros necesarios para consultar, ejecutar o adaptar la transformación.

Qué encontrarás aquí

  • Mappings organizados por dominio para localizar rápidamente la transformación asociada a cada caso de uso.
  • Acceso a la documentación generada para entender las reglas, entidades y propiedades utilizadas en cada mapping.
  • Enlaces a las versiones RML y YARRRML para facilitar su ejecución, revisión y reutilización.
  • Referencia al repositorio de cada dominio para consultar la implementación y su evolución.

Mantenimiento
Los mappings se mantienen en mappings/mappings.json. Para añadir uno nuevo basta con incorporar una nueva entrada al JSON; el catálogo se actualiza automáticamente.
